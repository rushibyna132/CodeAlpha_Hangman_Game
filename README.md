# CodeAlpha Hangman Game

## Description
A simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Random word selection
- Letter-by-letter guessing
- Maximum of 6 wrong guesses
- Tracks guessed letters
- Handles repeated guesses
- Handles invalid input
- Displays win or game-over messages
- Allows the player to play again

## Technologies Used
- Python

## Concepts Used
- Lists
- Strings
- Random module
- While loops
- If-else statements
- User input and output

## How to Run
Run the Python program and enter one letter at a time when prompted.
